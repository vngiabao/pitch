# Funding Hunter command center

Mode: Operate. Audience: A Story founder choosing the next worthwhile application. Extend the existing Pitch OS visual system and the existing local Founder OS service. The user supplied the hierarchy, views, detail contents, approval boundaries and schedule, and asked to continue building without a separate prototype.

## Direction contract

THESIS: A recommendation and its uncertainty lead each opportunity. Surface real decision work before the full research archive.

OWN-WORLD: Inherit Pitch OS teal #176b63, foreground #182329, light #f8f9fa, white panels, cool neutral sidebar, small radii and sans type. State colors carry meaning; data tables carry scanning.

STORY: See what needs confirmation, what the Hunter researched, and what deserves application time. Open an opportunity to compare fit, eligibility, ready materials and remaining effort.

FIRST VIEWPORT: Existing sidebar on the left, command title and Run now above the decision notice and opportunity rows. The priority view defaults to Recommended. Unknown fit uses a visible range and a review label.

FORM: Precisely specified extension; no concept seed or identity replacement. Responsive navigation, filters, opportunity list, dedicated detail route and run report. No fabricated demonstration metrics.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
