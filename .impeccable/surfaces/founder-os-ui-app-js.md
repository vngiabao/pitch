# Applications and daily reports extension

Mode: Operate. Extend the existing Founder OS Application and opportunity-detail surfaces. Keep the inherited visual system, records, navigation and canonical-fact approvals.

## Direction contract

THESIS: Show what the agents can actually do today, and what blocks external actions. The user must be able to distinguish saved reports, sender setup, submission intent, confirmed receipt and uncertainty.

OWN-WORLD: Inherit DESIGN.md: restrained teal, cool light surfaces, Segoe UI, readable records, native controls and explicit text states.

STORY: Review application status, confirm facts, connect the report sender, read today's report, and pause or resume authorized agents. Credit limits and required account/payment conditions remain visible.

FIRST VIEWPORT: Existing sidebar and application-page heading, company-fact notice and Application Pilot status. The daily-report sender state and connection action follow directly. Per-application blockers sit beside its status.

FORM: Narrow existing-surface extension, code-led; no new visual-world choice or concept seed. Meaningful states and owner controls carry the design.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
